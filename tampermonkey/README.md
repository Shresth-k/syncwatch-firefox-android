# SyncWatch — Tampermonkey / Violentmonkey Userscript

The exact same SyncWatch experience as a single userscript — works in **Firefox for Android** (with Tampermonkey/Violentmonkey from the Firefox Add-ons store, no AMO signing required!), **Desktop Firefox**, **Chrome**, **Edge**, and **Brave**.

## 1-Tap Install
1. Install **Tampermonkey** (or **Violentmonkey**) in Firefox for Android or Desktop.
2. Open this direct install link in that browser:
   👉 https://raw.githubusercontent.com/Shresth-k/syncwatch-firefox-android/main/tampermonkey/syncwatch.user.js
3. Tap **Install**.

## How to Use
- **Host:** Open any video/anime page → open Tampermonkey's menu → tap **Open SyncWatch** → **Create Room** → tap the **Link icon** to copy the invite link and send it to your partner.
- **Partner:** Just tap the invite link in Firefox — SyncWatch automatically redirects straight to the host's video, joins the room, and syncs playback and episode changes.
- **Settings (`⚙` beside Sync):** Switch **Left / Pop-up / Right**, toggle **Fullscreen**, enter **Cam Only** mode (tap cam for 50% transparent `Controls` button), **Minimize**, **Hide/Show** individual cams to save data, or change the **Server URL**.

> **Note:** On HTTPS sites, Firefox will ask for Camera & Mic permission once per video site (tap **Allow** + **Remember**). Everything else — including cross-origin player iframes, episode sync, and automatic Render TURN fallback — works identically to the Firefox extension.
